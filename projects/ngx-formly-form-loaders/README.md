# ngx-formly-form-loaders

Part of the [Formly Designer](https://github.com/GrumpTech/formly-designer#formly-designer) libraries. Converts importers into a form loader service, allowing you to work directly with generated forms or pages.

## Getting started

### Install

Run `npm i @grumptech/ngx-formly-form-loaders`.

### Develop

- Run `npm install` to install the necessary npm packages.
- Run `npm run build` to build the library.
