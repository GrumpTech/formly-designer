# formly-converters

A collection of converter functions used across the [Formly Designer](https://github.com/GrumpTech/formly-designer#formly-designer) libraries.

## Getting started

### Install

Run `npm i @grumptech/formly-converters`.

### Develop

- Run `npm install` to install the necessary npm packages.
- Run `npm run build` to build the library.
